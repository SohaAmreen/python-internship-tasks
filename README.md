# Python Internship Tasks

Python projects completed during the SAM AI Technologies internship.

## Projects

1. **Calculator** (`calculator.py`): Performs add, subtract, multiply and divide on two numbers. Handles invalid input and division by zero.
2. **Basic Chatbot** (`chatbot.py`): A rule-based chatbot that replies to greetings using if-elif, functions and loops.
3. **Word Counter** (`word_counter.py`): Reads a text file and counts the words. Handles file-not-found errors.

## How to Run

python calculator.py
python chatbot.py
python word_counter.py
